# 🎓 Aplikasi PPDB Desktop (Python CustomTkinter & MySQL)

Aplikasi Desktop Penerimaan Peserta Didik Baru (PPDB) berbasis Python dengan antarmuka modern (CustomTkinter) dan database MySQL.

---

## 🛠️ Instalasi & Cara Jalankan

1. Pastikan Service MySQL di **XAMPP** sudah aktif.
2. Import database dengan mengeksekusi file `database/schema.sql` di phpMyAdmin.
3. Buka terminal di folder project, lalu instal library:
   ```bash
   pip install -r requirements.txt
